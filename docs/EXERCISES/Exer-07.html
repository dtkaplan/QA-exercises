Exercise 10 Fix these commands so that they store the numbers properly.

#| caption: Fixing names
#| min-lines: 5
1st_place_score <- 103
first day <- Sys.Date() + 20
second-day <- Sys.Date() + 21
TipAnswer

The problem in each case is with the name on the left-hand side of the storage arrow.

  1. Names must start with a character. So, first_place_score would be a sensible replacement, as would place_1_score.
  2. Spaces are not allowed in names. By convention, an underscore (-) is used to separate words in names: first_day.
  3. Hyphens are not allowed in names. Use an underscore instead: second_day.
