MCQ to devoirs_choices translation test

Translation rules used

  • Remove the choice prefix (1., 2., a., and so on) from the displayed text.
  • Map [correct] to correct: true; other choices use correct: false.
  • Map [hint: ...] to feedback: ...; omit feedback when no hint is given so the package default applies.
  • Trim surrounding whitespace from choice text and hint feedback.
  • Join a continuation line to the preceding choice with a space.
  • Preserve the source mcq label and inline setting in the comment above each translated chunk. These are not devoirs_choices YAML fields; Phase 2 uses them when creating the devoirs_selection() call.
  • The chunk label is a unique, valid R variable name for the parsed choice list.
